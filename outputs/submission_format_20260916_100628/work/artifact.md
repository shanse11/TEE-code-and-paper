# 模板迁移说明

## 载体与来源

- 原始模板：`投稿模版.doc`。
- 可靠转换载体：`work/投稿模版_WPS.docx`，由 WPS 将旧版 `.doc` 转换为 `.docx`，SHA-256 为 `2ff95d4de25a224fc0fe7b3e411e20c1c648f7e04226e910ee962dde62597150`。
- 正文唯一来源：`Hybrid_TEE_Rollup修改版.docx`。
- 迁移前以正文、公式和 SVG 各一项完成小范围渲染验证，再迁移全文。

## 保留的模板结构

- A4 页面设置、页边距、页眉页脚、首页期刊信息和 DOI 占位行。
- 模板原生段落样式、字符样式、多级编号定义及继承关系。
- 首页单栏与正文双栏分节结构；通栏图表通过局部分节实现。
- 标题、摘要、关键词、作者单位、正文、图题、表题、公式和参考文献使用模板实际存在的样式。
- DOI 保留模板占位符，不填写虚构出版信息。

## 内容插槽与重复规则

- 首页插槽依次为中文题名、作者、单位、通信邮箱、中文摘要和关键词、英文题名、英文作者与单位、英文摘要和关键词。
- 一级至三级标题使用模板多级编号，一级标题从 0 开始；只修改编号及明确章节引用。
- 图题和表题保留原稿文字，使用模板题注样式并设为黑色。
- 两张数据表保留可编辑 Word 表格，使用顶线、表头下横线、底线和必要分组横线，无竖线；表头重复，数据行禁止跨页拆分。
- 参考文献保留原稿 12 条及顺序，使用模板参考文献样式和悬挂缩进。

## 对象迁移约束

- 四幅指定 SVG 以嵌入型对象插入，OOXML 内保留 SVG 主对象及 PNG 兼容回退图；无浮动锚点和裁切。
- 公式以可编辑 OMML 表达；不明确的字符含义不猜测。
- 首页作者简介仅使用登记表明确事实；无英文作者简介时不自行翻译。
- 模板示例文章、示例作者、示例基金、教学说明、批注及遗留元数据已清除。

- PDF 逐页渲染为 9 页 PNG 并逐页检查；最终 PDF 从实际交付路径在 macOS Preview 中重新打开，显示 1/9 页。
- 未在 Microsoft Word 中验证显示效果，因此交付名称保留“待确认版”。
